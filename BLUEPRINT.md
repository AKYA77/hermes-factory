[docs/source/Factory.pdf](docs/source/Factory.pdf). Its complete extracted text is
[docs/source/Factory.extracted.txt](docs/source/Factory.extracted.txt).

Hermes_Factory_Final_Blueprint_v2_0.md is this same Factory.pdf under a different
name. The preserved PDF is therefore the authoritative original supplied for this
project; a separate Markdown upload is not required. This index does not pretend
to be an exact Markdown transcription. Consult the PDF for typography/formulas.

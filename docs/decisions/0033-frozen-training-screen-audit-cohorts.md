# ADR0033 — Frozen training screen calibration and prospective audit cohorts

Status: implemented v1 generated software scope; full screening acceptance open.

Retain a complete explicit sampling frame and hash-seeded audit selection before
native outcomes. CohortRequest/v1 binds existing current-code native calibration
audits, unattempted queued cost-shadow jobs, fixed worker estimator policy, finite
sample size≤128/frame≤256, seed, actor and exact attestation. Calibration and
prospective work use compatible profile/family/timeframe/confirmation/scenario/
code/policy subjects. Prospective training begins at least24h after calibration
ends, covering the estimator's maximum label elapsed time. Training reservations,
evaluation influence, source quarantine and canonical bytes are rechecked.

Migration012 makes cohort bodies/membership immutable. Prospective experiments
cannot be reused in another independent cohort; seed-only copies of an effective
experiment are rejected. Already attempted or completed native outcomes cannot
be retrospectively selected. Registration preserves pause and atomically retains
calibration audit bodies/native hashes, all frame descriptors, payload hashes,
selected hashes and lineage. Exact repeated requests retrieve the same cohort.

Selected members receive authoritative native replay even when the existing
exact-zero screen would otherwise prune. Exact-zero disagreement still trips
ADR0032; cost-proxy/native disagreement remains a preserved counterexample and
never enables approximate pruning. Native artifacts and audit lineage remain
bound to the frozen cohort; reports reverify calibration/observed artifact hashes.
All selected observations, rejected count, false negatives and a descriptive
Wilson95% interval are shown. Correlated hypotheses/labels do not become IID,
independent strategy qualification or a full-universe confidence guarantee.
The conservative shortlist keeps all candidates for native work except the
existing exact-zero rule, whose circuit breaker remains authoritative.

Version1 intentionally requires explicit generated cost-shadow contracts. It does
not support historical calibration yet and never authorizes approximation to prune,
including when the observed audit has zero failures. Prior known positive native
counterexamples cannot be tuned away. Historical admission-bound diagnostics,
further calibration/comparability/selection safeguards and representative resource
acceptance remain implementable work, rather than silently waived requirements.

CLI, authenticated role-separated APIs and a graphical checkbox workflow expose
eligible inputs, frozen cohorts, actual native feedback and exact-byte exports.
Actual desktop/mobile/native evidence: docs/milestone-frozen-screen-cohorts.md.
No fill, risk, cost, score, canonical data or validation criterion is changed.

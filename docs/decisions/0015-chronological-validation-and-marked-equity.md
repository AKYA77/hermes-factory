# ADR 0015 — Chronological protocol execution and executable-side valuation

Authority: original blueprint §§8–10 and the final end-to-end completion mandate.
The existing matching engine, spread/slippage, intended 3R, risk budget and source
quotes remain unchanged. Every protocol explicitly freezes its boundaries,
purge/embargo, refit budgets and decision criteria. No global ranking rule or
existing source/experiment identity is rewritten.

Migration 006 preserves immutable scientific protocols, per-fold training-region
links, frozen evaluation stages, retrospective reporting authorizations and final
reports. The offline coordinator advances one bounded stage at a time under its
existing worker/resource/fencing controls. Each chronological quarter creates a
separate persistent TPE study using only preceding training outcomes. A fixed
training-only equity/strategy-ID tie rule selects the forward candidate. Forward
metrics are never optimizer objectives. A separate final refit uses permitted
past data before the final holdout. Partial quarters and purged/embargoed ranges
are explicit in the report. Stale scientific source fails instead of rebasing.

A bounded predeclared training neighborhood checks stops, lookback, threshold,
valid adjacent timeframes and confirmation sensitivity. Every variant is a real
native evaluation with a strategy identity and parent training-run link. No
neighbor is selected from final holdout feedback. Final confirmation still uses
ADR 0014's immutable selection/consumption. Annual and pooled retrospective runs
reset/retain $20 according to their separate native contracts, never splice fold
P&Ls into a fictitious compounded account. Their role is report_only, not OOS;
authorization is tied to the already-consumed frozen candidate and exact report
contract and cannot authorize training. Reference versus pessimistic cost runs
are separately labeled.

Statistics report expectancy, profit factor, confidence, streak/recovery,
parameter-neighborhood dispersion and a declared Holm stepdown family. The report
explicitly warns that binomial summaries assume independent trade outcomes and
that its declared family does not correct all researcher discretion. Decision
criteria are required inputs, not silent new acceptance defaults. The current
protocol executor is enabled only for labeled synthetic USD-quote reference
profiles. VALIDATED_REFERENCE means controlled software reference evidence;
eligible_for_historical_validated_board remains false. Full historical monetary,
calendar, regime robustness and global selection-bias gates remain open. Do not
claim complete C6 or SOFTWARE_VERIFIED on this increment.

The native replay now independently values actual fill cash flows plus open
inventory at each effective liquidation-side quote and actual fill transition.
It records exact USD-quote marked equity, full-stream drawdown and insolvency;
partial open positions are marked, never fabricated closed. No orders/fills are
created by this valuation. Cash/inventory conservation is checked. A bounded
chronological min/max envelope is display-only; no canonical quote, replay input
or exact statistic is downsampled. Non-USD or unsupported contract units remain
explicit UNKNOWN_CONVERSION_OR_UNITS. Cross-currency accounting is the next
critical monetary task.

A new golden regression exposed different native precision/forensic strings for
Decimal-padded profiles sharing the same canonical fingerprint. Replay now uses
the fingerprint's canonical representation for native precision and sizing.
This fixes representation drift without changing numeric profile values. Mixed
partial exits now use actual stop-fill roles/timing for stop diagnostics; a
contradictory exit label is inconclusive, not inferred from a losing price.

Verification includes actual multi-quarter native refitting/forward/holdout/
neighborhood/annual/pooled/cost execution with restart, pure reference decision
fixtures that never enter official tables, and independent marked-cash golden
cases for both sides and partial open inventory. Current full check: 186 tests,
zero failures/errors/skips, Ruff and dashboard check/build pass. Wider validation,
actual instrument/reference support and full UI/product gates remain in progress.

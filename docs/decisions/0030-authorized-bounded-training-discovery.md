# ADR0030 — Authorized bounded training discovery

Status: implemented software scope; overall acceptance NOT_READY.

A catalog entry is evidence of stored bytes, never permission to train. A typed,
immutable discovery/v1 grant records exact profile fingerprints, UTC training
windows, declarative family/timeframe coverage, code revision, finite region,
trial and CPU admission limits, actor and attestation. Historical candidates also
require an active reviewed input admission. Generated inputs remain visibly
synthetic. No evaluation or holdout permission is inferred.

Discovery subtracts protected ranges, recorded evaluation influence, queued
validation windows and frozen non-training stages by instrument/evidence kind,
including dataset aliases. Unknown legacy influence conservatively excludes its
whole recorded footprint. Registration and proposal issue recheck scope inside
the database write transaction. Source quarantine/admission and canonical bytes
remain checked by existing search/worker paths. New source revisions invalidate
old grants through existing execution revision checks.

Migration011 records immutable policies, planned region protocols and source
rejections separately from mutable enablement/region controls and rotating source
cursor. A plan is durable before registration; SIGKILL recovery registers that
same identity once. A kernel-released discovery lock serializes maintenance.
Finite catalog pages rotate across sources; breadth uses instrument/dataset/
family/timeframe counts, while proposal scheduling retains measured CPU fairness
including retired regions. Corrupt sources and stale policies are isolated.
Exhausted regions retire without deleting outcomes. New eligible source partitions
can be registered after earlier regions exhaust, within the original grant.

CPU totals are admission guards using completed measurements, not hard process
CPU limits: bounded in-flight work may finish. Disabling discovery stops new
regions/proposals; queued work uses existing queue cancellation controls. Global
pause is preserved by registration and respected by maintenance. Defaults are
explicit research choices, including session08–16UTC; they are not broker facts.

The authenticated API, CLI and structured dashboard expose grants, controls,
regions, source errors and exact export. No dynamic strategy code, risk/cost/
fill/scoring/validation rule or canonical dataset was changed. A separate durable
engineering queue maps every acceptance requirement; scoped task completion does
not change parent gates or run an unattended coding service.

Verification and limits: docs/milestone-autonomous-discovery.md. Shared indicator
transforms, safe screening calibration, scientific/global qualification, genuine
all-instrument source correctness, target-host soak and full release remain open.
